# EcoBrain

Environmental audit platform helping companies measure and reduce their footprint.

## Features

- Online audit submission
- Dashboard with results
- Blog, pricing and legal pages
- Authentication API

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Framer Motion
- Neon Postgres
- jsPDF

## Getting Started

```bash
git clone https://github.com/ghostland-dev/eco-brain.git
cd eco-brain
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Feco-brain)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `JWT_SECRET`
- `NEON_NEON_DATABASE_URL`
